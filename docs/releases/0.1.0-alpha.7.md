# Modern Vyapari v0.1.0-alpha.7

This alpha clarifies the prototype around one job: helping a self-directed crypto trader
research an idea, draft and review a plan, then understand what the simulated monitor did.
Evidence-grounded plan critique is still being developed.

- The user reviews and arms every plan. The agent researches and drafts; evidence-grounded
  critique is still developing, and it cannot arm plans or place orders.
- The app does not claim to create an investment edge or guarantee profitable plans.
- Plans are monitored only while the app is running. Background and cloud operation are not
  part of this release's promise.
- This release updates product documentation and positioning. It does not add live order
  placement; all trading remains simulated.

See the [README](../../README.md) for the current prototype scope and the
[roadmap](../ROADMAP.md) for current work and known limits.
